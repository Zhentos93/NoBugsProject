# UI-тест-дизайн для итерации 2

## Депозит денег пользователем

### Название: пользователь может пополнить выбранный аккаунт

**ПОЗИТИВНЫЙ КЕЙС**

**ПРЕДУСЛОВИЯ:**

1. Через API админ создает нового пользователя с ролью USER.
2. Новый пользователь залогинен.
3. Через API пользователю созданы аккаунты ACC1 и ACC2.
4. Через API установлен баланс ACC1 = 100.0, баланс ACC2 = 250.0.
5. Открыта страница User Dashboard.

**ШАГИ:**

1. Нажать кнопку Deposit Money.
2. Открыть список Select Account (- Choose an account -) и выбрать аккаунт ACC1 (Balance: $100.00).
3. Ввести 100 в поле Enter Amount.
4. Нажать кнопку Deposit.

**ОЖИДАНИЕ:**

1. Открыта страница Deposit Money.
2. Отображается список Select Account (- Choose an account -), поле Enter Amount и кнопка Deposit.
3. В списке отображаются аккаунты пользователя с данными, соответствующими ответу API; выбран именно ACC1 (Balance: $100.00), а не ACC2.
4. В поле Enter Amount отображается введённая сумма 100.
5. После нажатия кнопки Deposit UI отображает успешный результат пополнения выбранного ACC1 на 100 (✅ Successfully deposited $100 to account ACC1!) и не отображает результат ошибки. Проверка через API подтверждает: баланс ACC1 = 200.0, баланс ACC2 = 250.0; сумма зачислена ровно один раз.

## Перевод денег с одного аккаунта на другой

### Название: пользователь может перевести деньги другому пользователю

**ПОЗИТИВНЫЙ КЕЙС**

**ПРЕДУСЛОВИЯ:**

1. Через API админ создает 2 новых пользователей (отправителя и получателя) с ролью USER.
2. Новый пользователь-отправитель залогинен.
3. Через API отправителю созданы аккаунты ACC1 и ACC2.
4. Через API установлен баланс ACC1 = 1000.0, баланс ACC2 = 50.0.
5. Новый пользователь-получатель залогинен.
6. Через API получателю создан аккаунт ACC3.
7. Через API установлен баланс ACC3 = 200.0.
8. Открыта страница User Dashboard авторизованного пользователя-отправителя.

**ШАГИ:**

1. Нажать кнопку Make a Transfer.
2. Выбрать режим New Transfer.
3. Открыть список Select Account (- Choose an account -) и выбрать ACC1 (Balance: $1000.00).
4. Поле Recipient Name оставить незаполненным, т.к. не соответствует контракту API.
5. Ввести номер аккаунта ACC3 в поле Recipient Account Number.
6. Ввести 100 в поле Amount.
7. Установить флажок Confirm details are correct.
8. Нажать кнопку Send Transfer.

**ОЖИДАНИЕ:**

1. Открыта страница Make a Transfer.
2. Отображается форма New Transfer: список аккаунтов отправителя, поля Recipient Name, Recipient Account Number, Amount, флажок подтверждения Confirm details are correct и кнопка Send Transfer.
3. В качестве источника выбран именно ACC1 (Balance: $1000.00), а не ACC2; данные аккаунтов соответствуют ответу API.
4. Поле Recipient Name осталось незаполненным, т.к. не соответствует контракту API.
5. В поле Recipient Account Number отображается номер ACC3.
6. В поле Enter Amount отображается введённая сумма 100.
7. Флажок подтверждения Confirm details are correct установлен.
8. После нажатия кнопки Send Transfer UI отображает успешный результат перевода 100 на ACC3 (✅ Successfully transferred $100 to account ACC3!) и не отображает результат ошибки. Проверка через API подтверждает: баланс ACC1, = 900.0, баланс ACC2 = 50.0, баланс ACC3 = 300.0; сумма списана и зачислена ровно один раз.

## Изменение имени пользователя

### Название: пользователь может изменить своё имя на допустимое

**ПОЗИТИВНЫЙ КЕЙС**

**ПРЕДУСЛОВИЯ:**

1. Через API админ создает нового пользователя с ролью USER.
2. Новый пользователь залогинен.
3. Открыта страница User Dashboard.
4. В блоке профиля в шапке отображаются Noname и @username.

**ШАГИ:**

1. Нажать на блок профиля с именем и username в шапке.
2. В поле Enter new name ввести Ivan Ivanov.
3. Нажать кнопку Save Changes.

**ОЖИДАНИЕ:**

1. Открыта страница Edit Profile.
2. Отображается поле Enter new name и кнопка Save Changes.
3. В поле отображается введённое значение Ivan Ivanov.
4. После нажатия кнопки Save Changes UI отображает успешный результат изменения имени (✅ Name updated successfully!) и не отображает результат ошибки. После обновления страницы в блоке профиля в шапке отображается Ivan Ivanov, username не изменился. Проверка через API подтверждает имя Ivan Ivanov в профиле пользователя.
